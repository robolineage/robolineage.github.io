RoboLineage: Agent-Native Data Lifecycle Governance Across Robot Policy Iterations

Agents connect evidence, data, and decisions across robot learning iterations.

Qian Luo1,2, Wentao Guo1,3, Zhennan Qin1, Nanchun Guo1, Yunhan Zhao1, Yi Ma1,2, Yanchao Yang1,2

1TranscEngram 2The University of Hong Kong 3Beijing Institute of Technology

Paper PDF arXiv Code Videos

RoboLineage organizes robot learning as a connected workflow. Agents work under shared contracts that define their evidence, responsibilities, and handoffs. Lineage links the resulting artifacts, so later stages and collection rounds can use the history behind each dataset and policy.

Abstract

We present RoboLineage, an agent-native data lifecycle governance system for robot policy iteration. Modern robot policies improve through repeated cycles of data collection and retraining. Teams still rely on local tools, scripts, and expert memory to review the evidence and decide which data to use or which policy to release. RoboLineage records how rollout evidence leads to dataset changes and how those datasets produce policy versions. Evaluation and release decisions remain linked to that history, including the plan for the next collection round.

Agents interpret embodied evidence and prepare accepted data for existing training stacks. They also assess dataset readiness and carry context across iterations through typed, validated artifacts. In real-robot manipulation workflows, RoboLineage makes routine policy iteration faster and more auditable while maintaining downstream policy performance.

Lifecycle artifacts

Rollouts, reviews, datasets, training records, evaluations, and recollection plans remain linked across iterations.

Shared work contracts

Agents follow explicit responsibilities, evidence requirements, and validated handoffs across the learning workflow.

Cross-round context

Later collection plans use dataset coverage, policy ancestry, and earlier evaluation evidence.

Policy quality remains close in the tested settings: mean success is 92.7% with RoboLineage-selected data and 93.1% with human-selected data across eight tasks. Each workflow selects 60 demonstrations from the same 100-candidate pool per task and evaluates 60 trials (paper Figure 4).
